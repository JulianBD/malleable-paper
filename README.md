# malleable-paper

A paper that writes back. You write in your own words; the paper reorganizes
them into operable structure; every inference is tendable. Event-sourced: the
log is authoritative, every view (web UI, markdown, vault notes) is a
projection.

This is the project umbrella. Work starts from true scratch, bootstrapped by
using the tool itself.

## Layout

- `prototypes/` — prior art, kept runnable. Each is a prototype *of* this
  project, minted into this folder rather than archived.
  - `interaction/` — the Wordgard UX prototype (own git repo, frozen).
    Proved the interaction model: lift/move/settle provenance animation,
    tend menus, steering, frames as day/thread coordinates, `/where`
    content-by-query, widgets as keyed objects.

Vault pointer: `kb:malleable-paper` (`type: remote`, `#project`).
